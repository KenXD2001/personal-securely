# Securely Authentication Website

Securely is a modern authentication website built with React, TypeScript, TailwindCSS, and Vite. It includes functionalities such as login, account creation, password reset, and personalized user homepages.

## Features

1. User Authentication (Login, Register, Forgot/Reset Password).
2. Themed layouts (Auth and HomePage layouts with light/dark mode toggle).
3. Personalized user details on successful login.
4. Responsive and accessible UI.

## Tech Stack

- React
- TailwindCSS
- TypeScript
- Vite
